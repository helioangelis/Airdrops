# Airdrops — Rastreador de Projetos

App single-file HTML para acompanhar projetos cripto/airdrops (e outros): busca via CoinGecko, favoritos, listas customizadas, notas e prompt pronto para pedir atualizações via IA.

## Como usar (Termux)
```
curl -o index.html https://raw.githubusercontent.com/helioangelis/Airdrops/main/index.html
termux-open index.html
```

## Estrutura
- `index.html` — aplicativo completo (HTML+CSS+JS), dados salvos em localStorage no navegador.
